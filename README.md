# Hotel-Booking-Cancellation-Analysis
Hotel Booking Cancellation Analysis

Overview

This project investigates hotel booking cancellations using a dataset containing 119,390 bookings from two hotels in Portugal.

The analysis explores factors associated with cancellations and uses decision-tree classification to predict whether a booking will be cancelled.

Tools and Technologies

Python

pandas

seaborn

scikit-learn

Jupyter Notebook

Project Work

Exploratory data analysis and visualisation of hotel booking patterns.

Investigation of variables associated with cancellations.

Feature selection and data preparation.

Development and evaluation of decision-tree classification models.

Comparison of model performance using accuracy and confusion matrices.

Results

The final decision-tree model achieved 77.31% test accuracy, compared with 71.20% for the initial model.

Including market segment information and increasing the maximum tree depth improved predictive performance.
